# Portfolio Sistem Enterprise

Portfolio statis satu halaman untuk GitHub Pages.

## Isi Showcase

- Asset Management System
- GFO Leave & Permit System
- ITOPS Portal
- IT Command Center
- Mining Enterprise ERP
- Backlog Management
- PMO Governance System

## Cara Upload ke GitHub Pages

1. Upload seluruh isi folder ini ke repository GitHub.
2. Pastikan file `index.html` berada di root repository.
3. Masuk ke `Settings` > `Pages`.
4. Pilih branch utama, biasanya `main`, lalu folder `/root`.
5. Simpan dan tunggu GitHub membuat URL Pages.

## Catatan

Halaman ini tidak membutuhkan server, database, Laravel, atau XAMPP. Semua konten sudah dibuat sebagai HTML, CSS, JavaScript, dan aset lokal di folder `assets`.
